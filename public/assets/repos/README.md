# Repository Showcase Images

Place your custom repository preview images in this directory.
Supported formats: `.png`, `.jpg`, `.webp`, `.svg`.

Recommended image naming convention:
- `robotics.png` -> For bacondev123/robotics
- `meteor-dodge.png` -> For bacondev123/meteor-dodge
- `mathanimations.png` -> For bacondev123/MathAnimations
- `project-sao.png` -> For bacondev123/Project-SAO-Temporary-Discontinued-
- `chinese-game-project.png` -> For antigravityagent001/Chinese-game-project
- `profile.png` -> For antigravityagent001/profile
- `portal.png` -> For bacondev123/bacondev123.github.io

Images placed here will automatically be displayed on the corresponding repository card in the portal.
If an image is not yet provided for a repository, the card cleanly displays an authentic minimalist code header.
